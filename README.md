# AI-Driven Manpower Workforce & Financial Analytics

## 📌 Project Overview

This project focuses on analyzing manpower workforce and financial data to identify meaningful business insights related to workforce distribution, salaries, operational costs, contracts, and profitability.

Python is used for data cleaning, preprocessing, exploratory data analysis, and AI/ML analysis. Power BI is used to create interactive dashboards and visualize key business insights.

---

## 📊 Dataset Information

- ## 📂 Original Dataset & Source

- **Dataset:** KSA Manpower Supplier Financial Dataset 2024–2025
- **Source:** Prime Levels
- **Original Dataset URL:** https://prime-levels.com/data-hub/ksa-manpower-supplier-financial-performance-2024-2025
- **Dataset Size:** 4,000 contract-level rows
- **Format:** CSV
- **Type:** Synthetic Dataset
